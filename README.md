
# Coupling

A link-in-bio page builder for the SOEN 287 course project.

## Features

- Public landing page
- User registration and login (planned)
- Personal dashboard (planned)
- Link management (planned)
- Public user profiles (planned)
- Live page preview (planned)

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- JSON file storage (planned)

## Running the Project

1. Install Node.js.
2. Clone the repository.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000.
