
# Coupling

A link-in-bio page builder.

## Features

- Public landing page
- User registration and login 
- Personal dashboard 
- Link management 
- Public user profiles (planned)
- Live page preview (planned)

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- JSON file storage

## Running the Project

1. Install Node.js.
2. Clone the repository.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000.
